DeepSeek Harness — "Model + Harness = Agent"

DSH is not a model itself, but a runtime framework that connects models to real environments. All capabilities (terminal, browser, file system, search, UI, memory) are pluggable plugins via the Cordis system. npx @deepseek-ai/dsh web launches Web UI at 127.0.0.1:3080.

OpenClaw — "The AI that really does things"

GitHub's #1 starred repo (389k). Not just a coding tool — a full-spectrum personal AI assistant that runs 24/7, connects to IM platforms (WeChat/Feishu/DingTalk/Telegram), controls browsers, manages schedules, and more. v2.0 (2026-08-31) added multi-person collaboration.

DeepSeek Harness Security Note

According to a Tencent Zircon Lab report, DSH's plugin system has prompt injection risk — malicious content can embed instructions in plugin return values, inducing the Agent to execute unintended operations. Additionally, a study of 11,000+ DSH plugins found that official plugin governance mechanisms are nearly non-existent. The team has acknowledged these issues and is working on improvements.
